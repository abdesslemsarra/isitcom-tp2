# Site de l'ISITCOM — Projet pédagogique Git & GitHub

Ce petit site sert de support au TP Git & GitHub.
Le but n'est pas d'apprendre le JavaScript, mais de **suivre l'évolution
d'un projet avec Git** : commits, branches, fusion, publication sur GitHub.

## Version 1 (actuelle)

Une seule page qui présente l'ISITCOM, avec un bouton « Accès étudiant »
qui ne fait encore rien.

| Fichier      | Rôle                                  |
|--------------|---------------------------------------|
| `index.html` | Page d'accueil (contenu)              |
| `style.css`  | Mise en forme (couleurs, police, ...) |
| `README.md`  | Description du projet (ce fichier)    |

## Lancer le site

Ouvrir `index.html` dans un navigateur (double-clic). Aucune installation n'est nécessaire.
